# Claude Code use

Claude Code reads project `CLAUDE.md`. Copy the sample [CLAUDE.md](../CLAUDE.md) to the target, or ask Claude to follow [AGENT_SECURITY_GUIDE.md](../AGENT_SECURITY_GUIDE.md). Run the CLI offline first and review coverage. See the [Claude Code feature overview](https://code.claude.com/docs/en/features-overview) for project instruction behavior.
