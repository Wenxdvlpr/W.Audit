# Security policy

To report a suspected vulnerability, use the canonical GitHub repository's **Security → Report a vulnerability** workflow (GitHub private vulnerability reporting). If that option is unavailable, do not post vulnerability details publicly; contact the project owner through the repository's published profile or wait until private reporting is enabled.

Do not disclose vulnerability details, working exploits, or secrets in public issues. Include affected versions, reproduction steps, and impact in the private report. No response-time promise is made for this public beta. The repository owner must enable GitHub private vulnerability reporting for the workflow to be available.
